# NLP From Scratch — 全领域实验地图

**领域**：自然语言处理  
**任务覆盖**：文本分类 · 词元分类 · 表格问答 · 问答 · 零次射击分类 · 翻译 · 总结 · 特征提取 · 文本生成 · 填充掩膜 · 句子相似度 · 文本排名

每一步：**概念 → 最小实现 → 真实输入 → 可观察输出 → 与上一步对比 → 新增能力**

```
从零实现 ──► 经典方法 ──► 关键突破 ──► 现代系统 ──► 前沿方法
   S00–S02      S03–S05      S06–S10      S11–S14      S15–S16
```

| ID | 阶段 | 关键思想 | 主要任务 | 算力 |
|----|------|----------|----------|------|
| **S00** | Bag-of-Words + Naive Bayes | 词袋计数 + 贝叶斯 | 文本分类 | CPU |

| **S02** | 共现/Skip-gram 嵌入 | 分布假说 | 特征提取、相似度 | CPU |

| **S04** | TextRank 抽取式摘要 | 图排序 | 总结 | CPU |
| **S05** | 检索式 QA | 检索+答案跨度 | 问答 | CPU |
| **S06** | 神经文本分类 (Emb+CNN/MLP) | 端到端表征 | 文本分类 | T4×2 |
| **S07** | BiLSTM 词元分类 (NER) | 序列标注 BIO | 词元分类 | T4×2 |
| **S08** | 字符/词级 RNN LM | 自回归生成 | 文本生成 | T4×2 |

| **S14** | Cross-Encoder 精排 | 交互式打分 | 文本排名 | T4×2 |
| **S15** | 表格问答 (TAPAS/T5) | 结构+文本 | 表格问答 | T4×2 |
| **S16** | 统一现代流水线 | 多任务系统 | 全部任务验收 | T4×2 |
