# Multimodal Learning Roadmap

## 能力轴

| 轴 | 问题 | 对应阶段 |
|----|------|----------|
| 感知编码 | 像素/波形/帧如何变成向量？ | FS01–02, FS09–10 |
| 跨模态对齐 | 图与文如何共享空间？ | FS05 |
| 条件生成语言 | 给定视觉如何吐字？ | FS03–04, FS06–07 |
| 条件生成媒体 | 给定文/图如何出图/视频？ | FS11–12 |
| 检索 | 文档/页面如何被「看见」再被找到？ | FS07–08 |
| 统一 | 任意输入→任意输出如何路由？ | FS13–14 |

## 任务 ↔ 阶段

| 用户任务 | 主阶段 | 依赖 |
|----------|--------|------|
| 图像文本转文本 | FS03–05 | FS01–02 |
| 视觉问答 | FS06 | FS05 |
| 文档问答 | FS07 | OCR+检索 |
| 可视化文档检索 | FS08 | 补丁嵌入 |
| 视频文本转文本 | FS09 | 帧编码 |
| 音频文本转文本 | FS10 | 频谱 |
| 图像-文本-图像 | FS11 | 扩散/先验 |
| 图像-文本-视频 | FS12 | 时序生成 |
| 任意对任意 | FS14 | FS13 |

## 验收标准

每阶段必须产出：
1. `results/fsXX_*.json` 指标与样例 I/O
2. `figures/fsXX_*.png` 至少一张可观察图
3. `PROGRESS.md` 更新
4. 与上阶段的一句话对比
