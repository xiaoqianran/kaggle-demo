# Speech & Audio · From Scratch 实验地图

覆盖：文本转语音(TTS) · 文本转音频 · 自动语音识别(ASR) · 音频转音频 · 音频分类 · 语音活动检测(VAD)

## 总路线

```
从零实现 → 基础能力 → 经典方法 → 关键突破 → 现代系统 → 前沿方法
```

| 阶段 | ID | 主题 | 关键问题 | 方法 |
|------|----|------|----------|------|
| 0 | S00 | 声波与频谱 | 声音是什么数字？ | 波形 / 采样 / STFT / Mel / MFCC |
| 1 | S01 | VAD 从零 | 哪里在说话？ | 能量门限 → 谱特征 → 现代VAD思想 |
| 2 | S02 | 音频分类 | 这是什么声？ | 手工特征+分类器 → Mel-CNN |
| 3 | S03 | ASR 经典 | 如何把声变成字？ | 模板匹配/DTW → 端到端直觉 |
| 4 | S04 | ASR 突破 | 对齐难题 | CTC 玩具模型 |
| 5 | S05 | ASR 现代 | 开箱即用识别 | Whisper-tiny 推理 |
| 6 | S06 | TTS 从零 | 如何发声？ | 共振峰/谐波合成 |
| 7 | S07 | TTS 声码器 | 谱→波 | Griffin-Lim / mel invert |
| 8 | S08 | 文本→音频 | 非语音声音 | 过程式合成 + 标签驱动 |
| 9 | S09 | 音频→音频 | 变换与增强 | 变调/变速/去噪/轻量转换 |
| 10 | S10 | 全链路 | 系统拼图 | VAD→ASR→改写→TTS 最小闭环 |

每步契约：`概念 → 最小实现 → 真实输入 → 可观察输出 → 与上一步对比 → 新增能力`
